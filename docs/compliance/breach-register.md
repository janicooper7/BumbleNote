# Personal data breach register

UK GDPR Art. 33(5) requires a record of **every** personal data breach, including ones that don't need reporting. Fill this in whenever personal data is lost, exposed, altered, or unavailable when it shouldn't be. Examples:

- a report emailed to the wrong student
- audio that outlived the retention sweep
- a leaked API key or database credential
- an outage that loses lesson data

**Deadlines:**

- **ICO:** within **72 hours** of becoming aware, unless the breach is unlikely to put anyone at risk (report at ico.org.uk/for-organisations/report-a-breach). Report what you know, and add the rest later.
- **Tutors, for their student data** (see `/terms#data-processing`): without undue delay. They may have to report it to the ICO themselves.
- **Affected people:** without undue delay, if they face a high risk.
